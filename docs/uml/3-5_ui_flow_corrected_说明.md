根据“航旅智行”系统的用例及交互关系，系统通过以下界面区域和组件支持旅客操作。

- 行程创建区（Dashboard.vue）：录入航班、日期、起降机场及行李情况，提交行程。
- 行程仪表盘区（Dashboard.vue）：展示分析状态、航班信息、风险与行动建议，并提供重试和清除本机记录入口。
- 阶段确认组件（StageConfirm.vue）：上报当前位置或手动确认所处环节，嵌入仪表盘显示。
- 导航入口组件（NavigateButton.vue）：在存在导航数据时打开外部地图应用或网页。

行程创建或恢复成功后，页面显示仪表盘；位置或阶段上报后在原页面刷新；点击导航打开外部地图，用户可返回仪表盘；清除本机记录后返回创建区。创建区与仪表盘区均由 Dashboard.vue 实现，系统界面流跳转关系如图3-5所示。
