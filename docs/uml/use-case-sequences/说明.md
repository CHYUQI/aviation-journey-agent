# 五个用例顺序图说明

## 1. 创建行程

Dashboard.vue 的 submit() 先调用 validate() 和 buildPayload()，再把 payload 传给 createJourney(payload)。JourneyHandler.Create(c) 校验并构造行程，调用 Runtime.CreateJourney(journey)；Runtime 通过 MemoryStore 保存行程和初始进度，调用 publishProcessing(journey) 发布处理中快照，再调用 analyzeAsync(journey.ID) 启动后台分析。前端取得 accepted 后，通过 saveJourney(accepted.journeyId, payload) 保存本机记录，并调用 store.load(accepted.journeyId) 加载行程。

## 2. 查看行程状态与建议

行程状态容器的 load(id) 调用 getState(id)，JourneyHandler.State(c) 经 Runtime.GetSnapshot(id) 从 MemoryStore 读取完整快照，前端以其中的 state 和 advice 展示状态与建议。随后 createStream(id, apply) 建立订阅；JourneyHandler.Stream(c) 先调用 Runtime.Subscribe(id)，由 SSEHub 创建订阅通道，再读取并发送当前快照。前端通过 onSnapshot(snapshot) 回调 apply(snapshot)，更新本地快照并调用 clearFallback()。

## 3. 更新位置或确认所处环节

定位路径由 reportLocation() 调用 locate(props.journeyId)，浏览器定位成功后调用 updateLocation(journeyId, {lat, lng})；阶段确认路径由 pick(stage) 调用 confirmStage(props.journeyId, stage)，再调用 updateLocation(journeyId, {stage})。两条路径都进入 JourneyHandler.UpdateLocation(c)，随后 Runtime.ApplyLocation(id, req) 读取行程与进度、更新并保存 JourneyProgress，再发布处理中快照并启动后台重算。只上报坐标时清除此前手动确认的阶段；只上报阶段时保留已有坐标。

## 4. 打开前往出发机场的地图

ActionCardList.vue 在 action.nav 非空时，把该导航对象作为 nav 属性传给 NavigateButton.vue。点击按钮执行 open()，先用 setTimeout(callback, 1200) 设置网页回退，再注册 visibilitychange 监听，并把 window.location.href 赋为 props.nav.app。若定时器触发前发生 visibilitychange，监听回调调用 clearTimeout(timer)；否则定时器回调把 location.href 赋为 props.nav.web。

## 5. 清除本机行程记录

Dashboard.vue 的 removeJourney() 先调用 clearSavedJourney()，由 localStorage.removeItem(STORAGE_KEY) 删除本机记录；随后调用 store.reset()。reset() 调用 stop() 关闭 EventSource 订阅，并通过 clearFallback() 清理定时器，之后清空 snapshot 和 lastReady。Dashboard.vue 同时清空行程标识及提示状态，再通过 blankForm() 重置创建表单。
